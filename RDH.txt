Title: Regent Document Header (RDH)
Type: Governing Template
Role: Standard metadata header to be applied to all Regent documents
Standing: Required on all formal Regent documents; optional on informal drafts and fragments
Scope: All document types — project docs, articles, session gleanings, governance companions, correspondence

________________

I. Purpose Statement

The Regent Document Header (RDH) is the standard metadata header applied to all formal Regent documents. It identifies a document, locates it within the archive, declares its governing alignment, and makes its status legible to agents, collaborators, and the Prime without requiring the reader to read the full document first.

The RDH is a template — it does not govern. It is a consistent structural layer that sits at the top of any Regent document. It may be completed in full or with N/A where fields do not apply. No field is left blank.

________________

II. Usage Rules

1. Required on all formal Regent documents prior to archive placement.
2. Optional on in-progress drafts, fragments, and working notes — but recommended.
3. Fields marked [REQUIRED] must be completed before a document is considered archive-ready.
4. Fields marked [IF APPLICABLE] may be marked N/A where they do not apply.
5. No field is left blank. Use N/A, TBD, or [Pending] where the value is not yet known.
6. Agents may complete the RDH on behalf of the Prime and flag for review.
7. The Prime has final authority over all RDH field values upon archive placement.

Document Type: [REQUIRED] One of: Governing Constant / Governing Companion / Governing Template / Project Document / Session Gleaning / Article / Essay / Correspondence / Fragment / Other
Project: [IF APPLICABLE] Name of the project this document belongs to, or N/A
Series: [IF APPLICABLE] Name of the series this document belongs to (e.g., He Must Reign, RCF Series), or N/A

Date Created: [REQUIRED] YYYY-MM-DD
Date Last Modified: [REQUIRED] YYYY-MM-DD or [Current Session]
Version: [IF APPLICABLE] Version number or draft stage (e.g., v1.0, Draft 2, Final), or N/A
Current Status: [REQUIRED] One of: Draft / In Progress / Review Pending / Archive-Ready / Archive-Stabilized / Canon / Deprecated
Disposition: [REQUIRED] One of: RETAIN-Active / RETAIN-Archive / FLAGGED-Suggest Delete / PRIME DECISION-Pending
Governing Alignment: [REQUIRED] List the governing Constants and Companions this document operates under (e.g., TUOP, REG-COLLAB, SEGA)

Agent Notes: [IF APPLICABLE] Any notes, flags, or observations from the drafting agent(s), or N/A

IV. Field Definitions

Document Title
The full, formal name of the document as it will appear in the archive and in citation.

Short ID / Handle
A working abbreviation used in governance references, agent communication, and the AO registry. Not all documents have one.

Document Type
Classifies the document within the Regent framework. Use the controlled vocabulary above. If no type fits, use Other and describe.

Project
If the document belongs to a specific project (e.g., He Must Reign, RCF), name it here. If it is archive-wide or governance-level, use N/A.

Series
If the document is part of a named article or essay series, name the series. Otherwise N/A.

Author / Prime Voice
The human author and Prime voice. In the Regent context this is ordinarily Christopher Hart.

AI Collaborator(s)
Any agent who participated in drafting, development, or synthesis. Note the platform as well (e.g., Comet / Perplexity). Use N/A if no agent was involved.

Date Created
The date the document was first created, in ISO 8601 format (YYYY-MM-DD).

Date Last Modified
The date the document was most recently substantively changed. Use [Current Session] if modified in the present session and the date is not yet finalized.

Version
Tracking version or draft stage. Not all documents require versioning. Use N/A if not versioned.

Current Status
The document's current lifecycle stage. Controlled vocabulary:
  Draft — working, not yet complete
  In Progress — actively being developed
  Review Pending — complete but awaiting Prime review
  Archive-Ready — complete and ready for placement
  Archive-Stabilized — placed and stable; may be updated by proper means
  Canon — governing, authoritative, fully ratified
  Deprecated — superseded or retired

Disposition
The document's archive disposition per the system defined in AO Section III.
  RETAIN-Active — alive and in use
  RETAIN-Archive — complete and preserved
  FLAGGED-Suggest Delete — candidate for removal (Prime approval required)
  PRIME DECISION-Pending — awaiting Prime directive

Governing Alignment
List the Constants and Companions that govern this document's scope, voice, and treatment. At minimum, all Regent documents are under TUOP.

Archive Location (Drive)
The Google Drive folder or document link where this document lives. Use [To be placed] if not yet archived.

Archive Location (GitHub)
The GitHub raw or blob URL. Use N/A for documents that are Drive-only.

Directory Flow
The human-readable archive path in the notation established by TUOP Section IX (e.g., Regentorium / Governance / Templates).

Related Documents
Documents that are directly related: predecessors, successors, companion treatments, or cross-references.

Prime Notes
Any directive, context, or annotation from the Prime about this document.

Agent Notes
Observations, flags, or promissory notes from the drafting agent. Extensible — agents may add fields here as needed for their own tracking without disrupting the standard header.

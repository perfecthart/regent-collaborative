I. Purpose Statement

The Project Overview (PO) is the canonical definition of a project. Every substantive Regent project — a theological series, a book, a governance initiative, a research body — should have a PO. It tells any reader, agent, or collaborator what the project is, why it exists, what it is meant to produce, who is involved, and where it lives in the archive.

The PO is not a plan. It is a definition. Plans change; the PO captures the essential, stable identity of a project. It is updated only when the project's fundamental identity changes — and such a change ordinarily warrants a PCM.

One PO per project. The PO lives in the project's root folder in the archive.

________________

II. Usage Rules

1. Create one PO when a project is formally opened.
2. The PO is created by the Prime or by an agent on the Prime's behalf, and ratified by the Prime.
3. The PO is updated when a PCM is issued that changes the project's scope, collaborators, or governing alignment.
4. No field is left blank. Use N/A or TBD where values are not yet known.
5. The PO is archived in the project root:
   Regentorium / Core Projects / [Project Name] / PO_[ProjectHandle].txt
